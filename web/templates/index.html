게시 공개 상태:
💡 Google OAuth 연동 방법: Google Cloud 콘솔에서 OAuth 2.0 클라이언트 ID(데스크톱 앱)의 client_secrets.json을 config/ 폴더에 넣으시면 1회 승인 후 24시간 완전 무인 자동 업로드됩니다. (미등록 시에도 영상 제작 및 다운로드, 쇼룸 갱신은 100% 정상 작동)
🎤 AI 목소리 & 보이스 클로닝(내 목소리 영구 복제) 설정 ElevenLabs / Edge-TTS
🎙️ 내 목소리로 100% 동일하게 말하게 만드는 법 (초간단 3단계):
1. ElevenLabs.io 가입 후 VoiceLab > Add Voice > Instant Voice Clone 클릭
2. 스마트폰 음성녹음기로 조용한 방에서 내 목소리를 30초~1분 녹음한 파일(mp3/m4a) 업로드
3. 생성된 Voice의 Voice ID와 API Key를 위 입력칸에 넣고 [설정 저장]을 누르면, 모든 영상이 내 목소리로 자동 나레이션됩니다!
