# 🛠️ AutoThreads AI 운영 및 실전 활용 가이드

본 문서는 시스템의 최초 설정, 일상 운영, 계정 연동 및 트러블슈팅 매뉴얼입니다.

---

## 1. 최초 설정 및 환경 구성

### ① 프로그램 실행
1. 프로젝트 폴더의 [`start_automation.bat`](file:///c:/Users/pc700/OneDrive/ドキュメント/ai/쓰레드%20자동화/start_automation.bat)을 더블 클릭합니다.
2. 자동으로 브라우저에서 웹 관제 대시보드(`http://127.0.0.1:8080`)가 열립니다.

### ② 대시보드 API 설정 (`[⚙️ 운영 전략 & API 설정]` 탭)
* **쿠팡 파트너스:**
  * API 발급자: `Access Key` & `Secret Key` 입력
  * API 미발급자: `🔗 내 대표 파트너스 링크`에 쿠팡 간편 링크 또는 리틀리 링크 입력
* **Threads(메타) 연동:**
  * Meta for Developers에서 발급받은 Threads `Access Token` 입력
  * 시스템이 토큰을 통해 사용자 ID(`@salim.curator_`)를 자동 감지하므로 User ID는 비워두거나 자동 채움 유지
  * **발행 모드:** `[실제 자동 발행 모드]`로 설정
* 입력 완료 후 **[설정 저장하기]** 버튼 클릭!

## 2. 24시간 무인 자동화 운영 원칙

* **컴퓨터 관리:**
  * 검은색 CMD 창을 **최소화**해 두시면 프로그램이 백그라운드에서 24시간 내내 상시 대기합니다.
  * 윈도우 절전 모드(Sleep)는 "화면만 끄기"로 설정해 두는 것을 권장합니다 (본체 절전 시 스케줄러 일시 정지 방지).
* **골든타임 스케줄:**
  * 아침 07:30 (출근길 트래픽)
  * 점심 12:30 (점심시간 트래픽)
  * 밤 21:30 (심야 쇼핑 트래픽)
* **1:3 비율 자동 유지:**
  * 3번의 정보성/공감성 글이 배포된 후 1번의 수익화 글이 자동으로 배포됩니다.

## 3. 트러블슈팅 (자주 묻는 질문)

| 증상 | 원인 | 해결 방법 |
| :--- | :--- | :--- |
| **즉시 실행을 눌렀는데 쓰레드에 안 올라와요** | `발행 모드`가 `시뮬레이션 모드`로 되어 있음 | 대시보드 설정에서 `발행 모드`를 `실제 자동 발행 모드`로 변경 후 저장 |
| **포트 충돌 에러 (Errno 10048)** | 기존 프로세스가 포트를 점유 중 | 최신 버전은 자동으로 다음 빈 포트(8081, 8082 등)를 찾아 실행되므로 걱정 없이 재실행 |
| **쿠팡 API 키가 없는데 수익이 나나요?** | API 키는 15만 원 매출 후 발급됨 | 대시보드의 `내 대표 파트너스 링크`에 내 쿠팡 링크를 넣어두면 지금 당장 수익 적립 가능 |
