# 🤖 AutoThreads AI: 쓰레드 × 쿠팡파트너스 24시간 완전 무인 자동화 시스템

> **"사용자가 전혀 신경 쓰지 않아도 알아서 잘 나가는 상품을 소싱하고, 파트너스 딥링크를 변환하며, 섀도우밴 없는 고전환 카피와 카드뉴스를 렌더링하여 골든타임에 자동 배포하는 올인원 시스템"**

---

## 🌟 핵심 설계 원칙 및 기능 하이라이트

본 프로그램은 **[디노파인더 실전 활용법]** 및 **[쓰레드×쿠팡파트너스 자동화 가이드북]**의 핵심 알고리즘과 계정 정지(Shadowban) 방지 원칙을 100% 프로그램 코드로 구현하였습니다.

### 1. 잘 팔리는 상품 필터링 알고리즘 (4대 황금 카테고리)
* **가격대 필터:** **1만 원 ~ 3만 9,900원** (5만 원 이상 고가품 배제 ➔ 이탈 방지 및 즉시 결제 유도)
* **신뢰도 필터:** **리뷰 수 1,000건 이상 $\wedge$ 평점 4.5점 이상 $\wedge$ 로켓배송 필수**
* **4대 타겟 카테고리:**
  1. **생활용품:** 배수구 폼 클리너, 영구 다회용 먼지 롤러, 무타공 압축봉, 초미세 안개 분무기
  2. **아이디어/데스크테리어:** 마그네틱 자석 케이블 홀더, 360도 회전 노트북 거치대, 미니 전동 압축기
  3. **펫상품:** 실리콘 털 제거 브러시, 노즈워크 잔디 매트, 자동 급수기 활성탄 필터
  4. **다이어트/건강식품:** 알룰로스 저당 데리야끼 소스, 쉐이커 믹싱볼 보틀, 곤약 쫀드기

---

### 2. 5단계 무인 자동화 파이프라인

```
[1. 상품 자동 수집] ➔ [2. 파트너스 딥링크] ➔ [3. AI 카피 생성] ➔ [4. 카드뉴스 렌더링] ➔ [5. 쓰레드/인스타 배포]
```

1. **Step 1. 수집 & 필터 모듈 (`modules/sourcing/`):**
   * 쿠팡 골드박스 OpenAPI 및 타겟 카테고리 랭킹 상품 자동 탐색
   * 엄격한 조건 필터링 통과 상품만 SQLite DB(`data/automation.db`)에 적재 (중복 방지)
2. **Step 2. 파트너스 링크 변환 모듈 (`modules/deeplink/`):**
   * 쿠팡 공식 HMAC-SHA256 인증 API 연동 (`POST /v2/providers/affiliate_open_api/apis/openapi/v1/deeplink`)
   * 실시간 수익 추적용 딥링크(`https://link.coupang.com/a/...`) 자동 생성 및 검증
3. **Step 3. 글쓰기 엔진 (`modules/writer/`):**
   * **본문 절대 규칙 준수:** 300자 이내, 1문장 1줄(25자 내외), 2~3줄마다 줄바꿈, 이모지 최대 1개
   * **섀도우밴 원천 차단:** 본문 내 외부 링크 및 홍보성 단어("추천", "할인", "사세요") 완전 배제
   * **댓글 3단계 구조화:**
     * **댓글 1:** 공정위 필수 고지 문구 + 제품/가격/배송 요약 + 파트너스 링크
     * **댓글 2:** 실사용 디테일 꿀팁 (온도, 세척법 등) + 파트너스 링크
     * **댓글 3:** 자연스러운 참여 유도 및 마무리 + 링크
   * **1:3 안티 스팸 비율:** 수익화 글 1개당 순수 공감/정보성 글 3개 자동 교차 발행
4. **Step 4. 비주얼 카드뉴스 자동 렌더링 (`modules/visual/`):**
   * Pillow 기반 1080×1080 고해상도 카드뉴스 자동 생성 (인스타그램 & 쓰레드 겸용)
   * **Slide 1:** 후킹 헤드라인 + 로켓배송/리뷰 뱃지 + 상품 이미지 + 가격 + 댓글 확인 바
   * **Slide 2:** 구매 전 체크 3가지 포인트 카드
5. **Step 5. 플랫폼 연동 & 스케줄러 (`modules/publisher/`, `modules/scheduler/`):**
   * 전환율 최적 **골든 타임(07:30, 12:30, 21:30)** 자동 트리거
   * 봇 감지 회피용 **랜덤 지터(Jitter, ±15분 지연)** 적용
   * 댓글 등록 시 20초 자연 딜레이 적용

## 🚀 빠른 시작 방법 (원클릭 실행)

### 방법 1. `start_automation.bat` 더블 클릭 (가장 쉬움)
바탕화면이나 폴더에서 `start_automation.bat`을 더블 클릭하면:
1. 필요한 파이썬 패키지를 자동으로 점검 및 설치합니다.
2. 백그라운드 스케줄러와 웹 관제 대시보드를 즉시 시작합니다.
3. 브라우저에서 `http://127.0.0.1:8080` 대시보드가 자동으로 열립니다.

### 방법 2. 커맨드라인 직접 실행
```powershell
# 1. 1회 즉시 실행 테스트 (소싱 -> 링크 -> 카피 -> 카드뉴스 -> 발행)
python main.py --test

# 2. 웹 대시보드 및 24시간 스케줄러 가동
python main.py --host 127.0.0.1 --port 8080
```

## 🔒 계정 정지 및 섀도우밴 원천 방지 설계

1. **본문 URL 원천 제거:** 메타(Meta) 알고리즘은 본문에 외부 링크가 포함된 글의 도달 범위를 80~90% 축소합니다. 시스템은 본문에서 모든 URL을 강제로 제거하고 **오직 첫 번째 댓글**에만 배치합니다.
2. **공정위 문구 필수 하드코딩:** 파트너스 링크가 삽입되는 첫 번째 댓글에 공정위 필수 문구가 없으면 자동으로 삽입하여 법적 분쟁을 100% 방지합니다.
3. **1:3 청정 콘텐츠 비율:** 수익화 글만 연속으로 올릴 경우 계정 품질 지수가 하락하므로, 유용한 일상/살림 꿀팁 글이 3개 올라간 뒤 1개의 수익화 글이 올라가도록 알고리즘이 자동 분배합니다.
4. **시간 지터(Jitter):** 매일 정확히 같은 분/초에 올리면 매크로로 감지되므로, 골든타임 도달 시 `±15분` 범위 내에서 무작위 대기 후 인간처럼 자연스럽게 발행합니다.
